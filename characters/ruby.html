Ruby (disambiguation)

Ruby may refer to:

  • Ruby (homunculus) — Lalateya, the failed-prototype homunculus created by Gideon Azurith; the homunculus-era party’s Strength-stat frontliner (002 §Lalateya/Ruby, Archived Early Concepts).
  • Ruby (Skyward Cinders) — the Skyward Cinders main-party member, one of the four heroes implemented in the browser proto’s vertical slice (002 §Skyward Cinders - Main Party).

The name originated with the homunculus concept — a ruby is an alchemical tool/magical item, “she is a tool” (M00993, CrunchyConniptions, 2023-02-05) — and carried forward into the Skyward Cinders roster.
