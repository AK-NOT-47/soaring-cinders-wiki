Skill System (Slots, Modular Skills, Costs)

CANONSkyward CindersMixed
First conceived 2023-02-13 (M01870, FreshToast) · last in chat 2023-02-16 (M02172, CrunchyConniptions)

Skill System (Slots, Modular Skills, Costs) CANON

How characters acquire, slot, and pay for skills: a level-gated unlock cadence with no skill trees, position-dependent “modular” skills, and AP costs that scale with power. The proto ships a fixed 4-skills-per-hero list.

Summary — Skills are gained on a level-gated cadence (no skill trees — SCRAPPED anti-feature, “F**k skill trees”, 000 Part 3) with a small number of skill slots per character. Many skills are modular: one skill with two behaviors that switch on whether the caster is in the front or back rank. Every skill costs AP, with strength scaling roughly exponentially against AP cost. The vertical slice ships a concrete version: 4 skills per hero (two basics, one utility, one 4-AP finisher) as TypeScript constants (007 §Implemented Skill Roster).

For AP generation/spending rules see Action Points (AP) Economy (systems). Named skills live on Weapon Skills (Designed Roster), Character Skills (Per-Character Rosters), and Judgment Cut. Position mechanics are on the Combat Position System page (systems).

Skill acquisition & slots (design intent)

Progression is a refined, level-gated unlock cadence with NO skill trees and NO enemy scaling (007 §Level Structure Options).

  • 20-level structure CANON, leading: start at Level 1 with 2 skills and base attributes; Levels 2–20 alternate attribute/skill/trait gains. Odd levels give character skills, even levels give passive traits. End state: 4 character-skill slots, ~8 skills total (start with 2), ~5 passive traits (007 §Level Structure Options).
  • 10-level structure DEBATED, alternative: start with 3 starter skills; Levels 2–10 alternate trait and skill each level (007 §Level Structure Options).
  • The earlier “no leveling at all” stance (000 Part 6) EVOLVED into this refined cadence; the no-grind intent (tiny scaling, no treadmill) survives.

Modular skills

  • Definition: a skill with 2 uses that change depending on whether the character is in the front or the back rank (M01870, FreshToast, 2023-02-13). “Pretty common — most characters have them” (M01870).
  • Nearly every weapon gets a modular skill with a secondary effect that has movement attached (M01873, FreshToast, 2023-02-13).
  • Reverse modular: abilities that can target anybody but have different effects on either rank (007 §Modular Skill System).
  • Worked examples (Thane’s Spear): Leaping Strike “(Front → Back)” and Balanced Slash “(Front → Back)” with crit scaling on target resistance (M02171–M02172, CrunchyConniptions, 2023-02-16) — see Weapon Skills (Designed Roster). The Staff’s Modular AoE (both front or both back) is another (M02159, FreshToast, 2023-02-16).
  • Purpose: tactical depth, position-based gameplay, more strategic options (007 §Modular Skill System).

Skill costs (AP)

  • Every skill costs AP; skill strength should increase exponentially per AP cost (000 Part 3).
  • “Maybe nearly all character skills use AP” (000 Part 3).
  • If most fights end around turn 4, 4+ AP skills are finishers (000 Part 3). See Action Points (AP) Economy for the generate-vs-refill economy debate.

Implemented roster (proto vertical slice)

CANON The proto ships a fixed skill list as TypeScript constants; each hero carries 4 skills — two basics, one utility, one finisher at 4 AP (007 §Implemented Skill Roster; proto src/core/combat/content.ts).

  • Effect kinds in the proto: attack (single or scope: 'all'), heal, status, cleanse, move.
  • Finishers cost 4 AP and are gated to round 4+ or Escalation Mechanic 20 (e.g. Locke’s Emberlance, Thane’s Earthsplitter, Isaac’s Inferno, Ruby’s Benediction — 007 §Implemented Skill Roster).
  • Implemented skills carry rank constraints only (fromRanks / targetRanks) — there are no per-rank effect deltas yet, so the designed modular Front/Back effect-switching above remains design intent (007 §Implemented Skill Roster; GAME_DESIGN.md §5.8/§17).

Open questions

  • DEBATED 10-level vs 20-level structure and exact HP scaling left open (007 §Level Structure Options / §Unresolved Questions).
  • DEBATED Modular effect-switching not implemented — the proto has rank constraints but no per-rank effect deltas (007 §Implemented Skill Roster).
  • CANON, dropped No skill trees — rejected outright (000 Part 3).

Design history

  • 2023-02-13 — modular skill system defined: a 2-use skill that changes front/back; most characters have them; nearly every weapon gets a modular skill with movement attached (M01870, M01873, FreshToast).
  • 2023-02-16 — Thane’s Spear skills (Leaping Strike, Balanced Slash) and the Staff’s Modular AoE give concrete modular examples (M02159, M02171–M02172).
  • (later doc-era) — level-structure cadence formalized (20-level leading, 10-level alternative), skill trees scrapped; the “no leveling” stance evolved into the level-gated cadence (007 §Level Structure Options).
  • 2026-06-16 (proto reconciliation) — vertical slice ships fixed 4-skills-per-hero constants with rank constraints only; modular effect-switching recorded as unimplemented intent (007 §Implemented Skill Roster).
