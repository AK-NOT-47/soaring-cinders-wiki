Rank-Targeting / Combat-Readability UI

Cross-IterationNotes / Design
Also known as: Rank indicators, targeting UI, combat readability UI
First conceived 2023-02-06

Player-side visual feedback for how a skill’s rank/target range works and what the player has selected — distinct from the enemy-side intent telegraphs.

Summary — A player-facing readability layer for the rank/position system: colored indicators show which rank a skill can be used from (yellow) and which it can target (blue), potential targets are highlighted (with an AoE link), selection is made obvious via glow/halo, and enemy health that would be deleted is previewed Darkest-Dungeon-style (2023-02-06; 008 §7 Rank-Targeting UI). This is player-side targeting feedback — distinct from and complementary to the Enemy Intent Indicators; the two should not be duplicated. All conceived in a single 2023-02-06 readability thread; not implemented.

Description

(2023-02-06; 008 §7 Rank-Targeting / Combat-Readability UI)

  • Rank indicators on a skill: a yellow indicator shows which rank a skill can be used from; a blue indicator shows which rank it can target. Left arrow = left rank (back for party, front for enemy); right is the opposite. Framed as more immediately intuitive than text like “Skill only usable from back rank”.
  • Iteration / simplification: the blue symbol could be dropped so only the yellow appears.
  • Target highlighting: instead of a target symbol, highlight the enemies that are potential targets, with a visual link between them for AoE effects. Visual reminders sit underneath enemies; Darkest Dungeon does something similar with its “4 dots”.
  • Selection feedback: when a character is selected it should be more obvious — a drop-shadow glow under the character, a halo, or a low-effort eye-catching arrow; the health bar could change color or glow (from the same thread).
  • Enemy health preview (Darkest-Dungeon style): highlight the portion of an enemy’s health bar that would be deleted by the selected action (“the enemy themselves are highlighted and the portion of their [health] that would be deleted is highlighted” — noted as harder to implement). Otherwise show enemy health as numbers in the lower UI.

Related systems

  • Reads directly off the rank/position system — the yellow/blue arrows visualize a skill’s fromRanks/targetRanks.
  • Distinct from Enemy Intent Indicator System: that telegraphs what the enemy is about to do; this shows the player’s own skill range and selection. Complementary, not duplicative (008 §7 note).
  • Color note: the same 000 UI thread uses blue for a character’s position, orange for an enemy’s position on the combat map — separate from the yellow/blue skill-range indicators here.

Open questions

  • Whether to keep both the yellow (used-from) and blue (target) indicators, or drop the blue so only yellow appears (2023-02-06).
  • The DD-style health-deletion preview is the preferred option but noted as “more difficult to implement” (2023-02-06).
  • Whole system is / notes-design — not implemented in the proto.

Design history

  • 2023-02-06 — the entire proposal was worked out in a single combat-readability thread: yellow = used-from-rank / blue = target-rank arrows, the option to drop blue, potential-target highlighting with AoE links, selection glow/halo feedback, and the DD-style enemy-health-deletion preview with numbers in the lower UI. — no later revision recorded; remains .
