Anti-Meta Systems

Early ConceptNotes / Design
Also known as: Points System (Anti-Meta), Invasion System
First conceived 2021-05-25

Anti-Meta Systems

Systems designed to discourage everyone from converging on the single “best” build — because “everyone using the same builds is boring.”

Summary — Two anti-meta mechanics were discussed: a points system that makes the most popular characters/weapons/items expensive to field, and an invasion system where using the most powerful, popular hero makes you more likely to be invaded and have that power stolen (008 §14). Both belong to the early co-op-online vision; the invasion mechanic in particular is inseparable from the superseded Hero-vs-Undying framing, so this is preserved as a record rather than an active first-game system (008 §10 ).

Points system (anti-meta)

A system that disincentivizes meta builds/teams by cost (2021-05-25; 008 §14):

  • It is expensive to use the most popular character, weapons, items, etc.
  • If a player wants a specific build the point system “won’t allow,” they can still use it, but it loses effectiveness — less damage, longer cooldowns, and so on.
  • Guiding line: “Incentivize to embrace the randomness. Everyone using the same builds is boring” (008 §14).

This points idea is shared with the spirit-collection character-acquisition system, where points improve the probability of getting a certain character and can be retrieved once used, or spent on equipment/items/skills instead if the player “embraces the randomness” (008 §11). The design tension it expresses — “give people the ability to quell the randomness at a cost; people want to be in control” — is the same across both.

Invasion system (anti-meta)

A multiplayer anti-meta lever tied to the Hero vs Undying concept (2021-06-26; 008 §14):

  • “By using the most powerful and popular hero, you are more likely to be invaded and your power stolen.”
  • Purpose: “Disincentivizing people from just using the best heroes.”

Because invasion depends on other players invading yours to “borrow” a hero’s power, it only functions in the co-op-online model. See Two-Path System (Undying vs Heroes) for the full Hero/Undying framing this sits inside.

Open questions

  • Whether any anti-meta system survives into the single-player first game at all — both mechanics were built for online co-op (008 §10, §14; Parts 9-24). See Game Type & Structure (Overview).

Design history

  • 2021-05-25 — Anti-meta points system proposed: expensive to use the most popular characters/weapons/items; a disallowed build can still be used but loses large effectiveness (less damage, longer cooldowns) (2021-05-25; 008 §14).
  • 2021-06-26 — Invasion anti-meta emerges from the Hero/Undying two-path concept: using the best/most popular hero makes you a target for invasion and power theft (2021-06-26; 008 §10, §14).
  • Parts 9-24 — supersedes as active design. The first game is reframed single-player; the two-path/invasion framing (and thus the invasion anti-meta) is tagged an early/superseded concept, preserved as a record (008 §10 ).
