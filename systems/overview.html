Game Type & Structure (Overview) EVOLVED

The top-level shape of Soaring Cinders: what kind of game it is, how a session flows, and how the vision moved from a co-op online dungeon-crawler to a single-player JRPG.

Summary — Soaring Cinders is a turn-based JRPG with Dark Souls / soulslike adventure influences, character-based like Genshin Impact, focused on party building & optimization, battle, and exploration. The current articulation frames the first game as single-player, with co-op/multiplayer treated as a future or sequel aspiration rather than a launch feature (008 §1; Parts 9-24). Several Section-1 framings — a 100-floor dungeon, online cross-platform co-op — are recorded here as early-vision concepts that were later superseded (008 §1 EVOLVED).

Description (current vision)

  • Genre: JRPG with “coop dark souls adventure elements”; combat feel sits between Dark Souls and NieR: Automata (008 §1, §2).
  • Perspective: Third person; whether it is traditional top-down 2D or isometric 3D was still under discussion (008 §1).
  • Character system: Character-based, “similar to Genshin Impact” — a roster the player builds a party from (008 §1).
  • Structure: A dungeon-crawling adventure. The playable proto ships a compass-navigated node graph (start → fight → branch → camp → fight → boss), never a spatial map (008 §13 CANON · implemented). See the Design history below for the earlier 100-floor framing.
  • Focus areas: Party building & optimization, battle, and exploration (008 §1).

Core game loop

  • Bonfire and estus system from Dark Souls — rest points restore you; healing is scarce (008 §1). See Shields & Wounded State for the current health/healing model.
  • You never lose items or equipment you find — this is a load-bearing rule that survives across every iteration (008 §1; §9 “Never lose items or equipment you find”; §Summary of Core Design Pillars “Persistent Progress”).
  • Foster camaraderie by incentivizing playing with the same people again and again, so the player gets “the feeling of ‘we’ve been through so much together’” (008 §1). (This was written for the co-op vision; the sentiment carries into the single-player party’s cohesion.)

Core design pillars

The doc’s summary of pillars (008 §Summary of Core Design Pillars). Pillars marked below shifted with the single-player reframing:

  • Skill-Based Rewards — performance determines reward type (see Treasure & Rewards).
  • Player Choice — adjust difficulty on the go, not at the start (see difficulty).
  • No Time Limits — freedom and exploration over timed pressure; “time limits are taboo” (008 §19).
  • Minimal Maps — compass-based navigation preferred; “maps are taboo (debated)” (008 §19).
  • Combat Balance — between Dark Souls weight and NieR fluidity.
  • Strategic Depth — turn-based with intent indicators and positioning.
  • Persistent Progress — never lose found items/equipment.
  • Exploration Rewards — treasure hunting with meaningful rewards.
  • EVOLVED Coop-Focused (“start solo-able, scale to require teamwork”) and Character Collection (spirit/gacha with anti-meta incentives) belong to the early co-op vision; the first game is single-player (008 §Summary; Parts 9-24). See Spirit Collection System and Anti-Meta Systems.

Open questions

  • DEBATED 2D top-down vs isometric 3D perspective was never settled (008 §1).
  • EVOLVED The degree to which co-op ever returns (as a sequel/future goal) is aspirational, not scheduled (008 §1).

Design history

  • 2021-03-13 — First framing of “the gaming part”: “Coop dark souls adventure with engaging combat” (M00040, CrunchyConniptions, 2021-03-13). This is the origin of the whole game-type concept.
  • 2021-05-25 — Early core concept solidifies as a 100-floor dungeon, character-based (like Genshin), co-op online; early floors solo-able, later floors increasingly complex so co-op becomes central (Ghost of Tsushima nightmare-raids reference) (M00128, CrunchyConniptions, 2021-05-25; 008 §1, §13 Difficulty Scaling).
  • 2023 onward (Parts 9-24) — supersedes the above. The first game is reframed as a single-player JRPG; the 100-floor dungeon, online co-op, and cross-platform items are tagged EVOLVED early concepts, with co-op kept only as a future/sequel aspiration (008 §1 EVOLVED).
  • 2026-06-16 — Implemented-code pass: the proto ships the single-player structure as a compass-navigated node graph vertical slice; many notes-era systems (Remnants, Jet/Shard customization, the two-path system, NG+, anti-meta, spirit collection) are documented but not yet coded (008 §preamble).
