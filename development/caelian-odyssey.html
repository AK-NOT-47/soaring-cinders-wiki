Caelian Odyssey (Iteration)

Caelian OdysseyNotes / Design
Also known as: Caelian Odyssey: The Luminarium, Caelian Odyssy - The Luminarium
First conceived 2023-05-20

The project’s most recent in-chat iteration name (from late 2023): a turn-based JRPG built about the Luminarium magic academy — succeeding the earlier “Skyward Cinders” framing, and itself a former name, now superseded by the finalized title Soaring Cinders.

Summary — “Caelian Odyssey” is the name the team settled on for the game in late 2023 — the iteration succeeding Skyward Cinders, and itself later finalized as Soaring Cinders (see below). It was written on 2023-10-17 as “Caelian Odyssy - The Luminarium” (2023-10-17). The name first surfaced in May 2023 as the thing that should take priority over Project Magitech (2023-05-20). By October 2023 the JRPG was reframed to be about the Luminarium with no rival antagonist faction, its four non-mage party members recast as nonmagical historical/fictional archetypes around the mage Cyrus (2023-10-17). It is the successor iteration to Skyward Cinders, whose more character-conflict-driven framing it explicitly steps back from.

Finalized name — “Soaring Cinders”: the group’s current name for this game is Soaring Cinders (it is this wiki’s title). It refers to the same game the chats called Caelian Odyssey, and before that Skyward Cinders — three names for one continuous project across time. “Soaring Cinders” was adopted after the chat archive ends (2024-09-06), so the name itself does not appear in the source chats; the different titles are not different games. Project Magitech is the sole exception — a separate, shelved second-game concept, never part of this line.

What the iteration is

  • The turn-based JRPG as reframed in late 2023, titled “Caelian Odyssy - The Luminarium” (2023-10-17). The name was first used two months earlier when the team chose to prioritise it over Project Magitech (2023-05-20).
  • Design pivot: “No antagonist faction to the Luminarium” / “We’re gonna keep it about the Luminarium” (2023-10-17). The Luminarium magic academy is the iteration’s hub and centre of plot.
  • Party structure: the four “boyes” are each based on a nonmagical historical or fictional archetype (thief, samurai, knight, explorer/cowboy), while Cyrus is “a young, archetypal, fantasy mage and also representative of a well-rounded sorcerer by Caelian standards” (2023-10-17). “Caelian” is the setting-adjective (cf. the hub city Caelia).
  • Scope: by October 2023 the project spanned two narratives / two games — Caelian Odyssey plus the earlier/main game — with the river mechanic threaded across both plots (2023-10-13).

Relation to Skyward Cinders

  • Caelian Odyssey supersedes the “Skyward Cinders” working title/framing. Under Caelian Odyssey the party members’ “personal conflicts should be largely internal and (unlike Skyward Cinders) are highly secondary to the main plot (with the exemption of Cyrus)” (2023-10-17) — an explicit contrast with the prior iteration.
  • The two names briefly co-exist in October 2023 (2023-10-17, 2023-10-30), so the exact rename boundary is fuzzy — see Development Timeline for the timeline treatment.

Iteration lineage (for orientation)

  • Early-concept / co-op souls-like (2021): protagonist Leora; antagonists Lambent Corporation and Lucite. Scrapped.
  • Skyward Cinders (2023-02 → 2023-09): the JRPG restart; character-conflict-forward framing.
  • Caelian Odyssey: The Luminarium (2023-10 → 2024): the last in-chat iteration name, about the Luminarium; this page.
  • Soaring Cinders (finalized, post-archive): the game’s current real-world name — the same game as Caelian Odyssey / Skyward Cinders, just its settled title. This wiki is named for it.
  • Project Magitech: a separate, deprioritized second-game concept (not part of this game’s line) — see Project Magitech.

Open questions

  • Whether “Skyward Cinders” and “Caelian Odyssey” were parallel names for one iteration or a rename-in-progress; both appear in October 2023 (see Development Timeline Open questions).

Design history

  • 2023-05-20 — the name “Caelian Odyssey” first appears as the priority over Project Magitech.
  • 2023-10-13 — project confirmed as two narratives/games with the river mechanic spanning both.
  • 2023-10-17 — iteration named “Caelian Odyssy - The Luminarium”; reframed to be about the Luminarium with no antagonist faction; party recast as archetypes + mage Cyrus, explicitly contrasted with Skyward Cinders. This is the most recent in-chat iteration framing; the game’s current name is Soaring Cinders.
  • 2024-08 → 2024-09 — prologue screenplay drafted under the “CAELIAN ODYSSEY” title; worldbuilding continues to the archive’s end 2024-09-06.
