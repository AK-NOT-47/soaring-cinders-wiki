Caelian Odyssey (Iteration) CANON

The project’s final iteration (from late 2023): a turn-based JRPG built about the Luminarium magic academy, distinct from and succeeding the earlier “Skyward Cinders” framing.

Summary — “Caelian Odyssey” is the name the team settled on for the current iteration of the game, written on 2023-10-17 as “Caelian Odyssy - The Luminarium” (M04249, CrunchyConniptions, 2023-10-17). The name first surfaced in May 2023 as the thing that should take priority over Project Magitech (“Caelian Odyssey needs priority” — M03196, FreshToast, 2023-05-20). By October 2023 the JRPG was reframed to be about the Luminarium with no rival antagonist faction, its four non-mage party members recast as nonmagical historical/fictional archetypes around the mage Cyrus (M04226, M04306–M04307, FreshToast, 2023-10-17). It is the successor iteration to Skyward Cinders, whose more character-conflict-driven framing it explicitly steps back from.

Finalized name — “Soaring Cinders”: the group’s current name for this game is Soaring Cinders (it is this wiki’s title). It refers to the same game the chats called Caelian Odyssey, and before that Skyward Cinders — three names for one continuous project across time. “Soaring Cinders” was adopted after the Discord archive ends (2024-09-06), so the name itself does not appear in the source chats; the different titles are not different games. Project Magitech is the sole exception — a separate, shelved second-game concept, never part of this line.

What the iteration is

  • The current turn-based JRPG, titled “Caelian Odyssy - The Luminarium” (M04249, CrunchyConniptions, 2023-10-17). The name was first used two months earlier when the team chose to prioritise it over Project Magitech (M03196, FreshToast, 2023-05-20).
  • Design pivot: “No antagonist faction to the Luminarium” / “We’re gonna keep it about the Luminarium” (M04306–M04307, FreshToast, 2023-10-17). The Luminarium magic academy is the iteration’s hub and centre of plot.
  • Party structure: the four “boyes” are each based on a nonmagical historical or fictional archetype (thief, samurai, knight, explorer/cowboy), while Cyrus is “a young, archetypal, fantasy mage and also representative of a well-rounded sorcerer by Caelian standards” (M04226, FreshToast, 2023-10-17). “Caelian” is the setting-adjective (cf. the hub city Caelia).
  • Scope: by October 2023 the project spanned two narratives / two games — Caelian Odyssey plus the earlier/main game — with the river mechanic threaded across both plots (“TWO narratives now, in fact” — M04059, FreshToast, 2023-10-13; M04075).

Relation to Skyward Cinders

  • Caelian Odyssey supersedes the “Skyward Cinders” working title/framing. Under Caelian Odyssey the party members’ “personal conflicts should be largely internal and (unlike Skyward Cinders) are highly secondary to the main plot (with the exemption of Cyrus)” (M04226, FreshToast, 2023-10-17) — an explicit contrast with the prior iteration.
  • The two names briefly co-exist in October 2023 (Caelian Odyssey title M04249 on 2023-10-17; “Skyward Cinders” referenced M04226 same day and M04811+ on 2023-10-30), so the exact rename boundary is fuzzy — see Development Timeline for the timeline treatment.

Iteration lineage (for orientation)

  • Early-concept / co-op souls-like (2021): protagonist Leora; antagonists Lambent Corporation and Lucite. Scrapped.
  • Skyward Cinders (2023-02 → 2023-09): the JRPG restart; character-conflict-forward framing.
  • Caelian Odyssey: The Luminarium (2023-10 → 2024): the last in-chat iteration name, about the Luminarium; this page.
  • Soaring Cinders (finalized, post-archive): the game’s current real-world name — the same game as Caelian Odyssey / Skyward Cinders, just its settled title. This wiki is named for it.
  • Project Magitech: a separate, deprioritized second-game concept (not part of this game’s line) — see Project Magitech.

Open questions

  • DEBATED Whether “Skyward Cinders” and “Caelian Odyssey” were parallel names for one iteration or a rename-in-progress; both appear in October 2023 (see Development Timeline Open questions).

Design history

  • 2023-05-20 — the name “Caelian Odyssey” first appears as the priority over Project Magitech (M03196, FreshToast).
  • 2023-10-13 — project confirmed as two narratives/games with the river mechanic spanning both (M04059, M04075, FreshToast).
  • 2023-10-17 — iteration named “Caelian Odyssy - The Luminarium” (M04249, CrunchyConniptions); reframed to be about the Luminarium with no antagonist faction; party recast as archetypes + mage Cyrus, explicitly contrasted with Skyward Cinders (M04226, M04306–M04307, FreshToast). This is the current iteration framing.
  • 2024-08 → 2024-09 — prologue screenplay drafted under the “CAELIAN ODYSSEY” title; worldbuilding continues to the archive’s end 2024-09-06 (M05471–M05693; see Development Timeline).
