# Soaring Cinders — Lore Wiki

The public lore wiki for the **Soaring Cinders** JRPG, built from the team's
Discord design chats (2021–2024). 187 pages across 9 namespaces — every fact
traced back to a dated source message.

**Live site:** https://ak-not-47.github.io/soaring-cinders-wiki/

This repository holds only the published static site. It is generated from the
team's (private) design-docs repository; edits happen there and the built HTML
is published here.
