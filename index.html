The Lore Wiki

Soaring Cinders

Every character, place, creature, item, spell, and system — one page each, drawn from the group's Discord design chats (2021–2024). Most recent ideas are canon; each page's Design history shows how the idea evolved. Every fact traces back to a dated message.

“Soaring Cinders” is the finalized name for this one game — developed in the chats as Skyward Cinders (2023), then renamed Caelian Odyssey (late 2023). The different titles are the same game across time; only Project Magitech is a separate, shelved concept.
